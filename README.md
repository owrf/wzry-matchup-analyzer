# 王者荣耀对局分析工具

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

给巅峰赛玩家用的**对位分析 + 阵容方向判断**工具。

> 仓库：https://github.com/owrf/wzry-matchup-analyzer
> 欢迎提 Issue 补充对位数据、纠正英雄标签。

输入双方阵容，它会告诉你：**这局该往哪打、你的对位怎么处理**。

---

## 特点

| 特点 | 说明 |
|---|---|
| **官方数据** | 132 个英雄的技能原文（含等级数值），从官网抓取 |
| **AI 分析** | 基于技能原文做机制分析，不是凭印象瞎说 |
| **自带方法论** | 内置一套高分玩家总结的判断标准（三线半图分析、四问法、3:48 龙点等） |
| **共享数据库** | 分析结果自动缓存并共享——别人分析过的对位，你直接能用，不花钱 |
| **没 Key 也能用** | 查缓存 + 本地规则引擎，完全离线可用 |
| **你的 Key 不会上传** | 见下方「隐私」 |

## 快速开始

### 1. 装 Node.js

去 https://nodejs.org 下载 LTS 版，装完重启命令行。

验证：
```bash
node --version
```

### 2. 启动

**双击 `启动对局工具.vbs`**（Windows）

或者手动：
```bash
cd tools
node server.js
```
然后用浏览器打开 `http://127.0.0.1:8777`

### 3. （可选）配置 AI

点界面上的 **⚙️ 设置 API Key**，填入你的 DeepSeek Key。

- 申请地址：https://platform.deepseek.com
- 单次分析约 1800 tokens ≈ **0.002 元**
- **不填也能用**：会退回本地规则引擎（离线、免费、只做标签对比）

## 隐私（重要）

### 你的 API Key 永远不会发送到我们的服务器

```
你填 Key → 只存在你自己浏览器的 localStorage
    ↓
点「分析」时：浏览器 ──直接──→ DeepSeek API
    ↓
Key 不经过我们的服务器（也不经过任何第三方）
```

**技术依据**：
- **同源策略**：浏览器强制隔离，其他网站读不到本工具的 localStorage
- **本工具开源**：代码全部公开，你可以自己审查有没有偷偷上传 Key
- **可随时吊销**：在 DeepSeek 后台能立刻让 Key 失效，还能设额度上限

**残余风险**（诚实说明）：
- 如果用户装了恶意浏览器插件，或者电脑本身被入侵 → 跟任何网站一样躲不过
- 我们已尽量避免 XSS（所有渲染内容都是自己生成的，不用用户输入拼 HTML）

### 数据共享

**默认开启**：你的分析结果会匿名共享到公共数据库。

- 上传内容只有：**分析文本 + 英雄组合 + 分路**
- **不包含**：你的 API Key、你的身份信息
- 好处：别人分析过的对位你能直接用（不花钱），你的分析也能帮到别人

想关闭：删掉 `tools/matchup_cache.js` 里 `put()` 的远程上传调用（或提 Issue 加开关）。

## 数据来源与准确性

| 数据 | 来源 | 更新方式 |
|---|---|---|
| **英雄技能原文** | pvp.qq.com 官方英雄详情页 | 赛季更新后重抓 |
| **英雄标签**（定位/伤害/机动/坦度/线权等） | 人工整理 | 手工维护 |
| **对位记录** | 用户实战验证 | 每次修正都会累积 |
| **AI 分析** | DeepSeek，基于技能原文 | 自动缓存 |

**⚠️ AI 的分析是"基于机制的推理"，不是"实战验证过的结论"。** 你的对局才是最终标准，发现不对请用「修正」按钮。

## 赛季更新后怎么更新数据

```bash
cd tools

# 1. 重新抓取官网英雄数据（需要 Chrome 开着调试端口）
node fetch_hero_html.js      # 抓 132 个英雄页面
node parse_html.js           # 解析成 markdown
node make_herodata.js        # 生成前端用的 JS 数据

# 2. 重启服务
node server.js
```

**注意**：`fetch_hero_html.js` 需要 Chrome 带调试端口运行，详见 `启动Chrome调试.bat`。

## 目录结构

```
├── 对局分析工具.html      → 主界面（前端全部逻辑）
├── tools/
│   ├── server.js          → 本地服务（静态 + API 代理）
│   ├── config.js          → 配置管理（Key/端口/模型）
│   ├── profile.js         → ⚠️ 个人档案（改成你自己的）
│   ├── methodology.js     → 通用方法论（AI 提示词的一部分）
│   ├── matchup_cache.js   → 对位结果缓存
│   ├── make_*.js          → 数据生成脚本
│   └── fetch_/parse_*.js  → 官网数据抓取脚本
├── 英雄资料/
│   ├── herodata.js        → 132 英雄技能原文
│   ├── herotags.js        → 英雄标签
│   ├── lanedata.js        → 分路映射
│   ├── matchups.js        → 显式对位记录（人工/修正累积）
│   └── matchups_ai.json   → AI 分析缓存
└── config.json            → 你的配置（不进版本库）
```
